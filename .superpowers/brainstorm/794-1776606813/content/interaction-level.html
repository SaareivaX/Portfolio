Seberapa Interaktif?

Pilih intensitas animasi dan efek mouse. Semua tetap pakai Emil Kowalski principles (easing yang benar, timing yang tepat).

A

Subtle & Smooth — "Emil-style"

Animasi yang terasa benar tapi tidak mencolok. Setiap elemen punya purpose.

✓ Stagger entrance saat scroll ✓ Hover glow pada card ✓ Button scale on press ✓ Smooth page transitions ✓ Preloader animasi ✗ Custom cursor ✗ Mouse parallax
→ Lebih profesional, load ringan, tidak pernah terasa "ganggu"
B

Balanced — Fun + Polish ⭐ Recommended

Semua dari A, plus efek mouse yang terasa hidup dan menyenangkan tapi tidak berlebihan.

✓ Semua dari A ✓ Custom cursor glowing ✓ Hero foto tilt on hover (spring) ✓ Card hover: lift + glow border ✓ Magnetic button effect ✓ Floating particles di hero ✗ Full parallax layers ✗ Drag interactions
→ Balance antara fun & professional. Yang paling cocok untuk portfolio commsci
C

Max Fun — Full Interactive Playground

Semua efek diaktifkan. Portfolio terasa seperti experience, bukan sekadar halaman.

✓ Semua dari B ✓ Mouse parallax 3D di hero ✓ Text split char animation ✓ Glow trail mengikuti kursor ✓ Skill bars animasi counter ✓ Marquee teks skill scroll ✓ Cursor berubah per section
→ Paling wow, paling fun, tapi bisa terasa berat di device lambat
